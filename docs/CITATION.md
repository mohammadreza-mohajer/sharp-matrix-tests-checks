# Software citation

After creating the public repository, run `python tools/link_repository.py` with its actual GitHub URL. The command fills the URL in this citation and in `CITATION.cff`.

The bibliography entry for the journal paper is:

```latex
\bibitem{MohajerChecks2026}
M.~Mohajer,
\emph{Lean 4 formalizations and exact Python checks for
Sharp matrix tests and integral gluing over affine $p$-adic groups},
version~1.0.0, 2026, computer software.
\url{REPOSITORY-URL}.
```

Replace `REPOSITORY-URL` with the actual public repository URL. The paper files can remain with the journal.
