# Verification-only package

This package includes 33 previously checked Lean theorem declarations with their complete source and axiom records, 6,866 exact Python checks, and four companion searches with minima 7, 11, 19, and 7.

The Lean proof sources, configuration files, and recorded compiler outputs are identical to those in the full private package. The Python mathematical routines and classes are preserved. Their provenance output now uses citation metadata instead of reading the paper source. The modified programs are rerun and their outputs regenerated for this distribution.

Historical manuscript identification is documented explicitly in `paper_reference.json`.

The formalization scope is in `docs/FORMALIZATION_SCOPE.md`. Program outputs are in `python/`, and execution summaries are in `results/`. GitHub publication and journal submission have not been performed by this packaging step.
